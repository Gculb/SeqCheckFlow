HG002 regional benchmark

Direct command-line BWA/GATK runs were compared with SeqCheckFlow wrappers using the same inputs and settings. Each pair produced matching non-header VCF records. Accuracy below is truth-set accuracy within the GIAB confident bases for that interval. The preparation code accepts GRCh38 autosomes chr1–chr22, but retained end-to-end results cover chr20 and chr21 intervals only; other accepted chromosomes are not validated by these results.

F1 by region and confident-base coverage

F1 uses the left 0–1 scale; the narrow bars show what fraction of the requested 1 Mb interval was evaluated (right labels). Historical chr20 coverage percentage is not available in the retained summary.

Interpret with care: the intervals contain different loci and different scored truth variants, so their F1 values are not a controlled region-to-region comparison. The low chr21 interval has a very small evaluation mask and denominator; its score describes the scored loci, not the full megabase. Matching implementations demonstrate parity for these runs, not universal accuracy.

Airway RNA-seq example

An eight-library raw-read reanalysis of GEO GSE52778: four airway smooth-muscle donor cell lines, each untreated and dexamethasone treated.

Interpretation: no genes passed the selected adjusted-p threshold. CRISPLD2 had a positive estimated log2 fold change (+2.06), but high dispersion (0.86), a large standard error (0.95), and adjusted p = 0.9999. Its treated counts were higher in three donor pairs and lower in one. Four donors do not establish that dexamethasone has no biological effect.

Analysis path

  1. Resolve ENA runs to paired FASTQs; stream downloads to resumable partial files and check byte counts, MD5, and gzip integrity.
  2. Publish verified reads with per-sample download manifests.
  3. fastp trims adapters/low-quality bases and reports read QC; Salmon quantifies transcripts against Ensembl 112 / GRCh38.
  4. MultiQC and a per-sample QC summary combine fastp and Salmon metrics.
  5. tximport and DESeq2 fit the donor-adjusted model; outputs include normalized counts, gene variance/dispersion diagnostics, and plots.

Downloads stream to disk; fastp starts after each paired read set passes integrity checks. This workflow is separate from single-file checks and the HG002 variant benchmark.

Can we reproduce the study with these tools?

The current tools are enough to rerun our reanalysis: resumable ENA downloads, fastp, Salmon, tximport, DESeq2, and MultiQC process the eight GEO libraries with Ensembl 112 / GRCh38. This does not reproduce the paper's exact computation. Himes et al. (2014) used Taffeta, TopHat 2.0.4, Cufflinks/Cuffdiff 2.0.2, hg19 RefSeq plus ERCC references, and legacy QC tools. Those tools and reference bundle are not included here. The paper also reported qRT-PCR, Western blot, knockdown, cytokine, and genetic-association analyses that this project does not run. Our current DESeq2 result (zero genes at adjusted p < 0.05) therefore does not reproduce the paper's 316-gene result; it does not disprove the biological conclusion. See the GSE52778 record for the source experiment.

The run produces per-sample QC, normalized counts, and gene-level variance/dispersion diagnostics alongside DESeq2 results. The RNA-seq container does not pin every apt/R package to an exact version; for archival reruns, preserve its digest, tool versions, workflow revision, source-file checksums, and outputs. See the local run commands and full analysis report. The separate HG002 analysis is a methods benchmark comparing wrapper outputs and truth-set scores, not a biological hypothesis test; see the GIAB benchmark paper and NIST FAQ.
